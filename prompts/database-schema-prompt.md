# database-schema.md

Help me write a `database-schema.md` file for my project.

This document defines the complete data model for Sheybi.

It is the single source of truth for every entity stored by the platform.

It defines what data exists, how data relates to other data, who owns it, what fields are required, what can be modified, and what the prediction engine stores.

This is **not** an implementation document.

Do not include SQL, InstantDB schema definitions, migrations, ORM code, or framework-specific syntax.

Describe only the business data model.

## Writing Style

- Write in plain Markdown.
- Be implementation independent.
- Be concise but complete.
- Explain every concept before using it.
- Use deterministic language such as **must**, **will**, **cannot**, and **always**.
- Avoid vague wording such as **should**, **might**, **probably**, or **could**, except when discussing future improvements.
- Treat this document as the single source of truth for the Sheybi database.
